# proyecto_final_programacion

Nuestra aplicacion, es un catalogo de peliculas, este recaba la informacion a partir de una api que viene la de themoviedb,
la primera pantalla lo que hace es cargar en el carouselslider las peliculas recientes, en el movie slider que es lo que esta debajo del
carousel, carga las peliculas populares y debajo tenemos otro movie slider con las peliculas con una puntuacion mas alta, cada pelicula
es accesible con un click, donde encontraran una breve descripcion de las peliculas.

Seguidamente, si nos vamos al boton de search en el bottom navigation bar, podemos observar que unicamente al acceder a esta, se muestra
en la esquina superior derecha el icono para la busqueda, antes de ir a lo que hace la aplicacion al darle click a este icono, hablemos de
lo que se ve al acceder a esta pantalla, como podran observar, aqui se muestran una seria de peliculas por columnas estilo netflix, igualmente, al darle click podemos acceder a su descripcion y a medida que vamos bajando, van cargando más peliculas.

Ahora, retomando el icono de busqueda, al darle click, accedemos a una interfaz que nos permite escribir, en la parte izquierda del buscador tenemos un icono para salir de este y en la parte derecha tenemos otro icono para borrar todo lo que escribimos en el, al escribir, se van a mostrar automaticamente las peliculas que presenten el mismo titulo o similar y todo esto tambien lo recaba a partir de la api.

Por ultimo, tenemos el boton de perfil en el bottom navigation bar el cual simplemente muestra la informacion personal de los 3 integrantes del grupo y la materia cursada.
